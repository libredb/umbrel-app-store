# LibreDB Community App Store

An [Umbrel](https://umbrel.com) community app store that ships LibreDB Studio.

## Install

1. Open your umbrelOS dashboard and go to the App Store.
2. Click the three dots in the top right corner, then "Community App Stores".
3. Paste this URL and click Add:

```
https://github.com/libredb/umbrel-app-store
```

4. Open the LibreDB App Store and install LibreDB Studio.

## About the app

LibreDB Studio is an open source database IDE you run on your own server and
use from a browser. Nothing is installed on anyone's laptop, and the database
never has to be reachable from the internet. MIT licensed, no paid tier.

It ships 27 engine drivers of its own and reaches 55 engines in total, because
another 28 speak one of those wire protocols. Speaking the same protocol is not
the same as having the same catalog, so some of those 28 answer only in part,
usually missing row counts, sizes and the monitoring panels. The product
repository lists this engine by engine.

Source: https://github.com/libredb/libredb-studio
